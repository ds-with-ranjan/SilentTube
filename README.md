# 🔇 SilentTube

SilentTube is a Chrome Extension designed to eliminate distractions on YouTube and help users stay focused on learning.

Most people open YouTube with the intention of learning something, but quickly get distracted by Shorts, recommendations, comments, autoplay, and endless content suggestions.

SilentTube solves this problem by removing these distractions and creating a cleaner, more focused YouTube experience.

## ✨ Features

* ✅ Hide Shorts
* ✅ Hide Recommended Videos
* ✅ Hide Home Feed
* ✅ Hide Comments
* ✅ Hide Autoplay
* ✅ Hide End Screen Suggestions
* ✅ Hide Trending Page
* ✅ Lightweight and Fast
* ✅ Easy Toggle Controls

## 🚀 Why SilentTube?

The goal is simple:

**Open YouTube → Learn → Leave**

SilentTube helps students, developers, researchers, and professionals stay focused by reducing unnecessary distractions.

## ⚙️ Installation

### Method 1: Load Unpacked Extension

1. Clone this repository

```bash
git clone https://github.com/ds-with-ranjan/SilentTube.git
```

2. Open Chrome

3. Visit:

```text
chrome://extensions
```

4. Enable **Developer Mode**

5. Click **Load Unpacked**

6. Select the SilentTube folder

7. Open YouTube and enjoy a distraction-free experience
